# takahe-3d

Interactive 3D view of the Bedmap3 bed, ice surface and dated radar isochrones around Mt. Takahe, West Antarctica.

Live: https://jasonbott124.github.io/takahe-3d/ (acknowledgements and references: `about.html`, linked from the book icon; supplemental materials: `supplement.html`, linked from the flask icon)

Built with `layers_3D.py` from [TAKAHE_PROJ](https://github.com/jasonbott124/TAKAHE_PROJ); exported with `export_web.py`.
